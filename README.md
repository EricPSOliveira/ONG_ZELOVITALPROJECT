# ZeloVital

Website institucional desenvolvido para a ZeloVital, com foco em apresentar a organização, seus projetos e informações de forma clara, acessível e responsiva.

## Sobre

O ZeloVital é uma aplicação web institucional desenvolvida com foco em uma experiência de navegação simples, organizada e adaptável a diferentes dispositivos.

O projeto utiliza uma identidade visual própria e um Design System para manter consistência entre páginas, componentes e elementos da interface.

## Funcionalidades

- Navegação entre páginas
- Layout responsivo
- Menu adaptável para dispositivos móveis
- Formulários com validação
- Componentes visuais reutilizáveis
- Organização de conteúdo por seções
- Adaptação para diferentes tamanhos de tela

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Git
- GitHub

## Design

O projeto utiliza um Design System próprio para manter consistência visual.

### Cores principais

| Cor | Hexadecimal |
|---|---|
| Primária | `#314C37` |
| Secundária | `#627E54` |
| Terciária | `#446243` |
| Cards | `#F9F3D0` |

### Tipografia

A interface utiliza **Inria Serif** como parte de sua identidade visual.

### Responsividade

O layout utiliza um sistema baseado em **Grid de 12 colunas**, com diferentes breakpoints para adaptar a interface a desktops, tablets e dispositivos móveis.
